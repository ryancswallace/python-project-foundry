# Contributing

We welcome contributions to the `python-project-foundry` project!

Please follow the pull request (PR) process described below.

## Pull Request Process

0. For large or significant changes, discuss the change you wish to make by
   [opening an *issue*](https://github.com/ryancswallace/python-project-foundry/issues)
   on GitHub. Be sure to follow one of the project's issue templates.
1. [Open a PR](https://github.com/ryancswallace/python-project-foundry/pulls)
   following the project's PR template. Ensure all automated checks pass. Add a
   project maintainer as a reviewer.
2. Merge the PR after it's approved by a maintainer.
